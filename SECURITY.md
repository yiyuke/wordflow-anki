# Security Policy / 安全说明

## Supported versions / 支持版本

Security fixes are applied to the latest published Wordflow release. Before the first tagged release, they are applied to the current `main` branch.

安全修复会优先应用到最新正式版本。第一份带版本号的 Release 发布前，以 `main` 分支为准。

## Report a vulnerability / 报告安全问题

Please do **not** open a public Issue for a vulnerability, leaked credential, or report containing private data.

Use GitHub's private **Report a vulnerability** form on the repository's **Security** page:

<https://github.com/yiyuke/wordflow-anki/security/advisories/new>

请不要用公开 Issue 提交漏洞、泄露的凭证或包含私人数据的报告。请进入仓库的 **Security** 页面，使用私密的 **Report a vulnerability** 表单：

<https://github.com/yiyuke/wordflow-anki/security/advisories/new>

Include the affected Wordflow version, macOS and browser versions, reproduction steps, and the impact you observed. Remove API keys, personal Anki content, browsing history, and other secrets from screenshots or logs.

请写明 Wordflow、macOS 和浏览器版本、复现步骤及影响。提交截图或日志前，请删除 API Key、私人 Anki 内容、浏览记录及其他敏感信息。

Wordflow maintainers will never ask you to post an OpenAI API key in an Issue, Pull Request, screenshot, or log.

Wordflow 维护者不会要求你在 Issue、Pull Request、截图或日志中公开 OpenAI API Key。
